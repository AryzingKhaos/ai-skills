# 币圈个币 · 短期复盘（crypto-token-short-review）

面向 **加密货币个币** 的 **短期**（默认近 7 天）异动复盘。是 A股/美股两个 `*-short-review` 的姊妹 skill，思路一致、为币圈做了适配。

整条链路：**拉行情 + 识别短期异动（脚本，确定性）→ 拉 BTC/ETH 与同板块/生态币一起对比 → 逐个异动联网查因（多维度：个币 + 板块叙事 + 大盘 + 链上/衍生品 + 宏观监管）→ 写复盘报告**。

> 最核心的产出：**最近这几天的剧烈涨跌到底为什么**，并分清是「个币自身 alpha」「板块叙事联动」「BTC/ETH 大盘 beta」「链上/衍生品（如连环爆仓）」还是「宏观/监管」。**加密 24/7、无涨跌停、波动远大于股票**，且多数山寨高度跟随 BTC。平静期没有大波动，也要给一份「近况 + 板块/链上动向」简报。
>
> **本 skill 不止于"为什么"——必须在事实归因与多派会诊之后，落到一份明确、可执行的投资建议（方向＋力度＋操作要点＋改判条件＋置信度）。这是硬要求，不许以"仅供研究/非投资建议"回避表态。**

## 执行步骤

### 1. 解析输入
- 名称 → 符号（用 `WebSearch` 核对，别张冠李戴；注意同名/换名/重发币）。
- 识别板块叙事与生态（L1/L2/DeFi/AI/Meme/RWA/DePIN…，所属公链）。
- 时间区间 → `--start`/`--end`（按 `currentDate` 算；默认近 7 天）。
- 确认输出目录（默认见上）。

### 2. 跑脚本拿主标的异动
```bash
python3 <skill目录>/scripts/fetch_crypto.py <SYMBOL> --start <YYYYMMDD> --end <YYYYMMDD> \
    --day-threshold 8 --swing-threshold 20 --swing-window 7
```
输出 JSON：`meta`（符号/交易对/计价/窗口收益 `period_return_pct`/最新价）、`single_day_events`（含 `amplitude_pct` 振幅、`quote_volume_musd` 成交额百万美元）、`multi_day_swings`、`data_source`、`warnings`。先看 `ok`；注意 `data_source`/`quote`（USDT vs USD）与"最后一根可能进行中"。

### 3. 拉 BTC/ETH 与同叙事/生态币对比（关键，相当于"产业链联动"）
- **必拉 BTC、ETH**（大盘 beta 基准），再选 **3~5 个同板块叙事 / 同生态** 的币，对每个也跑 `fetch_crypto.py`（**同一窗口**），读各自 `meta.period_return_pct` 做**联动对比表**。
  - 例：标的是某 Solana 生态 Meme → 对比 BTC、ETH、SOL、以及其它热门 SOL 生态/Meme 币。
- 用对比判断：异动是 **跟 BTC 大盘动（beta）**、**同叙事齐动（板块）**，还是 **个币独立 alpha**（标的涨跌幅明显偏离 BTC/ETH 与同类）。

### 4. 逐个异动 + 平静期 联网研究（核心，务必多维度 + 诚实）
对**每个** `single_day_events` 和 `multi_day_swings`（平静期则对"近况"）联网查因，覆盖维度：
- **项目/币本身**：代币解锁 / 线性释放 cliff（token unlock，对山寨砸盘极关键——查解锁日历）、上币/下架（Binance/Coinbase/Upbit listing 拉盘、下架砸盘）、主网/升级/分叉/空投快照、黑客/漏洞/脱锚、合作/集成/被采用、基金会或团队/做市商转账抛压、治理提案、回购销毁。来源：项目官博/官方 X、交易所公告、区块浏览器。
- **板块叙事**：同叙事币是否齐涨齐跌、叙事轮动（narrative rotation）、龙头带动。
- **大盘（BTC/ETH）**：BTC/ETH 当窗走势（绝大多数山寨跟随）、BTC.D（比特币市占）、TOTAL/TOTAL2 总市值、风险偏好 risk-on/off。
- **链上 on-chain**：交易所净流入/流出、巨鲸地址异动、稳定币供应、活跃地址；DeFi 看 TVL（DefiLlama）。来源：Arkham/Nansen/Glassnode（多可经 WebSearch/WebFetch）。
- **衍生品 derivatives**：资金费率 funding rate、未平仓合约 OI、**多空爆仓 liquidations（连环爆仓常驱动急涨急跌——务必查）**、合约持仓多空比。来源：Coinglass。
- **宏观 / 监管**：美联储/利率/DXY、与美股(纳指)相关性、**现货 ETF 资金流（BTC/ETH ETF）**、SEC/各国监管与执法、稳定币立法。
- **情绪**：恐惧贪婪指数 Fear & Greed、CT/社媒热度。
- **归因分层**（必做）：拆成 **① 个币 alpha ② 板块叙事 ③ BTC/ETH 大盘 beta ④ 链上/衍生品（爆仓） ⑤ 宏观/监管**；能量化就量化（标的涨跌 vs BTC/ETH/同类）；**时间对齐**异动与事件（注意 UTC vs 本地时区）；分清"消息驱动"还是"提前反应/传闻/资金博弈"。
- **诚实第一**：只写有来源支撑的原因；**找不到明确催化就写「未找到明确催化（疑跟随大盘/资金/情绪/爆仓）」，绝不编造解锁、上币、合作或链上数字**；每条附来源链接+日期+置信度（高/中/低）。

### 5. 平静期（窗口内无显著异动）
仍要产出简报：近窗温和涨跌、与 BTC/ETH 的相对强弱、同叙事/生态近况、链上与衍生品（funding/OI 是否积累）、临近催化（解锁日、升级、ETF 数据、宏观事件），并明确说明"本窗无触发阈值的剧烈异动"。
