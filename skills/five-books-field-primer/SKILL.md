# Five Books Field Primer · 五本书击穿一个领域

输入**一个你想了解的领域**，按史蒂芬·科特勒（Steven Kotler）《跨越不可能》里的 **"the five books of stupid"（五本书击穿一个领域）** 框架，联网挑出 **5 本真实存在、循序渐进**的书：从最好玩的畅销书，一路读到该领域的前沿与未来，让你用最短路径搭起对一个领域的地基。

**理念**（忠于原书）：这套方法的目标**不是精通**，而是先"允许自己犯五本书的傻"——快速熟悉一个领域的术语、脉络和主流共识，为后续深入打地基。所以选书的关键是 **难度循序渐进 + 五本都聚焦同一领域**，而不是凑五本都是入门书。

整条链路：**领域归一 → 联网核验选书(五层各一本) → 合成清单(中文优先) → 终端打印 + 存 Markdown 归档 + 更新索引**。

## 触发约束（硬约束）

**只在用户显式调用时触发**：`/five-books-field-primer <领域>`、"用/调用 five-books-field-primer 挑 X 的五本书"、"给我 X 的入门到前沿五本书"。用户只是随口说"推荐几本书""我最近想学 X"、不算调用。

## 0. 领域归一

1. **确认领域边界**。用户给的可能是：
   - 刚好的领域（"行为经济学""量子计算""明代历史""葡萄酒品鉴"）→ 直接选。
   - **太宽**（"科学""历史""AI""金融"）→ 先提示会太发散，建议聚焦到一个子领域（如 AI → "大语言模型" / "AI 安全" / "AI 绘画"），或让用户给一个切入角度；用户坚持宽领域就选该领域最主流的一条主线。
   - **太窄 / 太新**（如某个刚出现两年的细分技术）→ 可能凑不齐 5 本成书，见 §3 的诚实降级规则。
2. **记录用户附加偏好**：是否偏理论/偏实操、是否有阅读基础（有基础可整体上移一档难度）、是否限定中文等。没说就按默认：零基础、中文优先、理论实操兼顾。

## 1. 五层框架（选书的分层标准）

严格按科特勒的五层，**每一层的定位不同、难度递增**，一本书只占一层：

| 层 | 名称 | 定位（选这本书的标准） |
|---|---|---|
| 书 1 | **畅销入门书（乐趣）** | 关于这个领域**最流行、最好玩**的书，虚构或非虚构都行。唯一目标是**乐趣**、点燃兴趣、混个眼熟。可以不严谨。 |
| 书 2 | **大众进阶书（兴奋）** | 仍然畅销好读，但**更专业、与主题相关性更强**，主要作用是把兴趣升级成兴奋、建立主干认知。 |
| 书 3 | **半专业书（精确）** | 第一本**半技术读物**：语言精确，开始出现**外行看不懂的专业术语和细节**，但仍勉强能读。 |
| 书 4 | **专家前沿书（最难）** | 五本里**最深奥**的一本。让你看到**真正的专家在思考什么问题**、领域的主流共识与最新进展；读完能开始形成自己的判断。 |
| 书 5 | **未来书（走向）** | 未必最难读，但**最难理解**：讲这个领域的**未来方向、发展节奏、前沿争论**，让你判断它往哪走、多快。 |

**选书铁律：**
- **循序渐进**：书1→书5 难度必须明显递进；不要给五本同层的书。
- **同一领域**：五本必须都在用户指定的这个领域内，别跑题到相邻领域（除非某层确实只能靠邻域经典支撑，需注明）。
- **中文优先**：优先推**有中译本**的书；某一层实在没有合适中文书，再给**英文原版**并明确标注"暂无中译本 / 需读英文"。
- **不同作者优先**：尽量五本出自不同作者/视角，避免同一作者包揽（除非该领域确实由某人奠基）。

## 2. 联网核验（必须联网；每本书都要确证存在）

**最重要的铁律：绝不编造书。** 模型记忆里的书名/作者/出版年常出错甚至凭空捏造，**每一本推荐书都必须实际联网打开条目确认它真实存在**，再写进清单。

按下表核验，交叉验证书名、作者、是否有中译本：

| 要素 | 权威来源 |
|---|---|
| 中文书存在性 / 中译本 / 译者 / 出版社 / 评分 | **豆瓣读书** `book.douban.com`（搜书名，打开条目页确认）、**微信读书** `weread.qq.com`、当当/京东图书页 |
| 英文原版存在性 / 原名 / 作者 / 年份 | **Goodreads** `goodreads.com`、**Amazon Books**、出版社官网、维基百科该书词条 |
| 这本书是否真的属于这一层 | 看简介/评论判断难度与受众（畅销科普 vs 教材 vs 专著 vs 前瞻），必要时搜"<书名> 书评 难度 适合谁" |
| 领域主流书单参考 | 搜"<领域> 经典入门书 / 进阶 / 专著 / 前沿"、知乎/豆瓣豆列/相关课程 syllabus，但**每本仍需回到上面权威源确证** |

> 实操：先按五层各想 1–2 个候选 → 逐个到豆瓣/Goodreads 打开条目确认存在、拿到准确书名作者年份与中译本情况 → 判断它落在哪一层 → 定稿。**查不到确证存在的书，就换一本；宁可这一层说明"较难找到理想中文书"，也不许编。**

### 数量与降级规则
- 每层**主推 1 本**；若某层有一本旗鼓相当的替代，可加**至多 1 本"备选"**并标注，不铺开成书单。
- 若领域**太新/太窄**凑不齐 5 本成书：**如实说明**，允许某一层用**权威长文 / 综述 / 会议报告 / 纪录片**替代，并明确标注"（非图书，因为该领域尚无合适成书）"。绝不为凑数硬塞不相关或不存在的书。
- 若某层**只有英文书**：照给，标注"暂无中译本"，并尽量补一句英文难度提示。

## 坑位备忘
- **绝不编书**：书名、作者、出版年、"有没有中译本"一律要先打开豆瓣/Goodreads 条目确认；模型记忆经常把书名张冠李戴或凭空造书。宁可换书、宁可某层说明难找，也不许编。
- **别把五本全选成入门书**：这是最常见的跑偏。书3必须开始"半专业"、书4必须是真专家在读的难书、书5必须讲未来——难度不拉开，这个方法就废了。
- **别跑题到相邻领域**：五本都要在用户指定的领域内。
- **领域太宽先收窄**：科学/历史/AI 这种级别的词，先帮用户聚焦一个子领域，否则五本书没法自洽递进。
- **忠于原书但如实标注局限**：这是科特勒一位畅销书作者的个人经验法则，不是同行评审过的科学定论——不必贬低，但也别包装成"权威共识"。
