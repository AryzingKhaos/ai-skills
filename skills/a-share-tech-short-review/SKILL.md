# A股科技股 · 短期复盘（a-share-tech-short-review）

面向 **A股科技股（芯片 / 半导体 / AI 及产业链）** 的 **短期**（默认近 5 个交易日）异动复盘。

整条链路：**拉行情 + 识别短期异动（脚本，确定性）→ 定位产业链位置并把上下游个股一起拉来对比 → 逐个异动联网查因（多维度：个股 + 产业链上下游 + 海外映射 + 板块资金）→ 写复盘报告**。

> 最核心的产出：**最近这几天的剧烈涨跌到底为什么**，并且必须分清是「个股自身 alpha」「产业链上下游传导」「板块/题材情绪」还是「大盘系统性」。消息面只是其中一维，**产业链上下游的股价联动与消息面同样要覆盖**。平静期没有大波动，也要给一份「近况 + 产业链动向」简报。
>
> **本 skill 不止于"为什么"——必须在事实归因与多派会诊之后，落到一份明确、可执行的投资建议（方向＋力度＋操作要点＋改判条件＋置信度）。这是硬要求，不许以"仅供研究/非投资建议"回避表态。**

## 执行步骤

### 1. 解析输入
- 名称 → 6 位代码（用 `WebSearch` 核对，别张冠李戴）。
- 判断是否 A股科技股（不是就按"适用范围"提示/确认）。
- 时间区间 → `--start`/`--end`（按 `currentDate` 算；默认近 5 交易日）。
- 确认输出目录（默认见上）。

### 2. 跑脚本拿主标的异动
```bash
python3 <skill目录>/scripts/fetch_ashare.py <code> --start <YYYYMMDD> --end <YYYYMMDD> \
    --day-threshold 5 --swing-threshold 10 --swing-window 5
```
输出 JSON：`meta`（代码/简称/板块/涨跌停幅度/窗口收益 `period_return_pct`）、`single_day_events`、`multi_day_swings`、`data_source`、`warnings`。先看 `ok`；注意 `data_source`（若 `sina` 则注明不复权、无成交额）。

### 3. 定位产业链位置 + 拉上下游/同业个股一起对比（本 skill 的关键增强）
- 判断该标的在 **芯片/半导体/AI 链** 的位置：上游（设备/材料/EDA/晶圆代工/存储）→ 中游（设计/制造/封测）→ 下游（终端/服务器/光模块/算力/云）。
- 选 **3~6 个关键上游 / 下游 / 同业 A股个股**，对每个也跑 `fetch_ashare.py`（**同一时间窗口**），读各自 `meta.period_return_pct` 做**联动对比表**。
- 用对比判断：标的的异动是**全链/板块一起动（beta）**，还是**自己单独动（alpha）**。例：标的 +12%、上游设备股同期 +10%、下游算力股 +11% → 多半是产业链共振；若只有标的大涨、同业平淡 → 个股专属催化。

### 4. 逐个异动 + 平静期 联网研究（核心，务必多维度 + 诚实）
对**每个** `single_day_events` 和 `multi_day_swings`（平静期则对"近况"）联网查因，覆盖维度：
- **个股消息面**：公告/业绩快报预告/订单/产能/扩产/中标/减持回购/股东/调研/诉讼。来源：东方财富 `data.eastmoney.com`、财联社 `cls.cn`、公司公告（巨潮 cninfo）。
- **产业链上下游消息面**：上游（光刻机/设备、硅片/材料、EDA、晶圆代工产能与报价、存储颗粒涨价）；下游（终端/手机/PC、AI 服务器、光模块/CPO、云厂商资本开支 capex、算力需求）；同业（联动或抢单）。
- **海外映射**：美股对标（英伟达 NVDA、台积电 TSMC、ASML、美光 MU、博通 AVGO 等）隔夜涨跌与财报、**费城半导体指数 SOX**、出口管制/实体清单动向——A股科技股常跟随隔夜美股科技/半导体。
- **政策 / 资金 / 板块**：国产替代、大基金、出口管制、科创50/半导体ETF/AI 指数当日表现、北向资金、板块涨跌停潮、龙虎榜（游资 vs 机构席位）。
- **归因分层**（必做）：把每次异动拆成 **① 个股 alpha ② 产业链传导(上下游) ③ 板块/题材情绪 ④ 大盘系统性**，能量化超额就量化（标的涨幅 vs 板块/上下游/SOX）。**时间对齐**异动日与消息日，分清"消息驱动"还是"提前反应/传闻"。
- **诚实第一**：只写有来源支撑的原因；**找不到明确催化就写「未找到明确催化（疑资金/情绪/技术性）」，绝不编造具体公告、数字或事件**；每条附来源链接+日期+置信度（高/中/低）。

### 5. 平静期（窗口内无显著异动）
仍要产出简报：近窗温和涨跌、产业链上下游近况与消息、海外映射、临近的催化（财报/解禁/行业数据/大会），并明确说明"本窗无触发阈值的剧烈异动"。

## 注意事项

- **短期高频用**：默认近 5 交易日，适合每天/每周看；窗口、阈值都可调（`--start/--end`、`--day-threshold/--swing-threshold/--swing-window`）。如需**长期复盘**，显式给更长区间并放大阈值/窗口（如 `--swing-threshold 15 --swing-window 20`）。
- **产业链维度不能省**：哪怕个股本身没消息，也要看上下游/同业/海外是否在动——很多科技股的异动是产业链传导或隔夜美股映射，而非自身公告。
- **诚实归因**：事后归因有局限，单日多利好并存时难精确拆分；找不到原因就如实写"未找到明确催化"，标注置信度，宁缺毋造。
- **复权说明**：默认 `qfq`（前复权），除权除息机械跳空不会被误判为异动；落到 sina 通道时为**不复权**，报告须注明。
- **板块/特殊**：脚本按代码段+名称推断涨跌停（主板±10、创业板/科创板±20、北交所±30、ST±5），涨停/跌停标注据此判定。
- **必须给出明确投资建议**（方向＋力度＋操作要点＋改判条件＋置信度），并附风险与降权说明；不得以"仅供研究/非投资建议"回避表态。
