# 美股科技股 · 短期复盘（us-tech-short-review）

面向 **美股科技股（半导体 / AI / 大型科技 及全球产业链）** 的 **短期**（默认近 5 个交易日）异动复盘。是 A股版 `a-share-tech-short-review` 的姊妹 skill，思路一致、为美股做了适配。

整条链路：**拉行情 + 识别短期异动（脚本，确定性）→ 定位全球产业链位置并把上下游/同业一起拉来对比 → 逐个异动联网查因（多维度：个股 + 产业链上下游 + 海外/宏观映射 + 板块资金）→ 写复盘报告**。

> 最核心的产出：**最近这几天的剧烈涨跌到底为什么**，并分清是「个股自身 alpha」「产业链上下游传导」「板块/题材情绪」还是「大盘/宏观系统性」。**美股无涨跌停、财报多在盘后**，所以单日异动要分辨「隔夜 gap（盘后财报/消息）」与「日内」。平静期没有大波动，也要给一份「近况 + 产业链动向」简报。

## 执行步骤

### 1. 解析输入
- 公司名 → 代码（用 `WebSearch` 核对，别张冠李戴）。
- 判断是否美股科技股（不是就按"适用范围"提示/确认）。
- 时间区间 → `--start`/`--end`（按 `currentDate` 算；默认近 5 交易日）。
- 确认输出目录（默认见上）。

### 2. 跑脚本拿主标的异动
```bash
python3 <skill目录>/scripts/fetch_usstock.py <TICKER> --start <YYYYMMDD> --end <YYYYMMDD> \
    --day-threshold 5 --swing-threshold 10 --swing-window 5
```
输出 JSON：`meta`（代码/名称/复权口径/窗口收益 `period_return_pct`）、`single_day_events`（含 `gap_pct` 隔夜跳空 / `intraday_pct` 日内）、`multi_day_swings`、`data_source`、`warnings`。先看 `ok`；注意 `data_source`/`adjust`（stooq=拆股调整、yahoo=未复权）。

### 3. 定位全球产业链位置 + 拉上下游/同业一起对比（关键增强）
- 判断标的在 **半导体/AI 链** 的位置：上游（设备 ASML/AMAT/LAM/KLA、代工 TSMC/Samsung/Intel、存储/HBM Micron/SK Hynix/Samsung、EDA Synopsys/Cadence、IP Arm）→ 中游（设计/IDM）→ 下游（云厂 capex 微软/谷歌/亚马逊/Meta、服务器 Dell/SMCI、终端 Apple、光模块/网络 Coherent/Arista）。
- 选 **3~6 个关键上游 / 下游 / 同业**（优先**美股或 ADR**，如 TSM、ASML、AMD、AVGO、MU、SMCI、ARM），对每个也跑 `fetch_usstock.py`（**同一窗口**），读各自 `meta.period_return_pct` 做**联动对比表**；**非美上市**（三星、SK 海力士等）只走新闻不取价。
- 用对比判断：标的异动是 **全链/板块一起动（beta）** 还是 **个股 alpha**。

### 4. 逐个异动 + 平静期 联网研究（核心，务必多维度 + 诚实）
对**每个** `single_day_events` 和 `multi_day_swings`（平静期则对"近况"）联网查因，覆盖维度：
- **个股消息面**：财报（earnings，**多在盘后**——优先看 `gap_pct` 大的日子是否对应财报/盘后消息）、业绩指引 guidance、产品发布、大客户/订单、分析师评级与目标价调整、回购、内部人/13F、8-K/SEC、诉讼/监管。来源：公司 IR、SEC EDGAR、CNBC/Bloomberg/Reuters、Seeking Alpha、analyst notes。
- **产业链上下游消息面**：上游（ASML/AMAT 订单与财报、TSMC 月度营收与产能/报价、HBM/存储涨价 Micron/SK Hynix、EDA）；下游（云厂 capex 指引、AI 服务器需求 SMCI/Dell、苹果/终端、光模块/网络）；同业（AMD/AVGO/QCOM 联动）。
- **海外 / 宏观映射**：费城半导体指数 **SOX**、ETF **SMH/SOXX/QQQ**、隔夜亚洲链（TSMC、三星、SK 海力士）；**美联储/利率/FOMC/CPI/PCE/就业**（科技股久期长、对利率与流动性敏感）、美元、**对华 AI 芯片出口管制**、台海地缘。
- **资金 / 情绪**：期权（gamma/0DTE）、ETF 资金流、大盘（标普/纳指）、VIX、财报季节奏。
- **归因分层**（必做）：拆成 **① 个股 alpha ② 产业链传导(上下游) ③ 板块/题材情绪 ④ 大盘/宏观系统性**；能量化超额就量化（标的 vs SOX/SMH/同业）；**时间对齐**异动日与消息日（注意盘后财报对应次日 gap）；分清"消息驱动"还是"提前反应/传闻"。
- **诚实第一**：只写有来源支撑的原因；**找不到明确催化就写「未找到明确催化（疑资金/情绪/技术性）」，绝不编造财报数字、订单或事件**；每条附来源链接+日期+置信度（高/中/低）。

### 5. 平静期（窗口内无显著异动）
仍要产出简报：近窗温和涨跌、产业链上下游/同业近况与消息、海外/宏观映射（SOX、即将公布的 CPI/FOMC、临近财报）、临近催化，并明确说明"本窗无触发阈值的剧烈异动"。

## 注意事项

- **美股特性**：无涨跌停；财报/指引多在**盘后或盘前**，故重点看 `gap_pct`（隔夜跳空）大的交易日是否对应财报/消息；交易日按**美东时间**；注意夏令时。
- **产业链/宏观维度不能省**：很多美股科技股的异动来自**同业/SOX 联动**、**亚洲供应链隔夜**或**美联储/CPI 等宏观**，而非自身公告；务必查上下游与宏观。
- **诚实归因**：事后归因有局限，找不到原因就如实写"未找到明确催化"，标注置信度，宁缺毋造。
- **数据口径**：Stooq=拆股调整价（未做分红调整）；落到 Yahoo 通道时为**未复权 close**；报告须注明。Stooq 偶遇反爬/Yahoo 偶遇 429 时脚本会自动回退/重试，仍失败则提示用户稍后再试或换网络。
- **短期高频用**：默认近 5 交易日，窗口/阈值都可调；长期复盘显式给更长区间并放大阈值/窗口。
- 非投资建议，报告须含免责声明。
