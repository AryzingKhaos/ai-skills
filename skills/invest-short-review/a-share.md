# A股部分 · invest-short-review

标的被判为 **A股** 时读本文，配合 SKILL.md 的共用骨架执行。本文只写 A股 专属的部分。

## 适用范围（A股 + 科技股）

只做 **A股** 的 **科技股**，重点是 **芯片 / 半导体 / AI** 及紧邻环节：半导体设备/材料/EDA、晶圆制造/封测、芯片设计、存储、消费电子/PCB/光模块/CPO、服务器/算力/IDC、AI 软件应用等。

- 用户给的若是**非科技股**（如白酒、银行、地产）：先**提示不在本 skill 专长范围**，问是否仍要继续（仍可跑，但产业链/海外映射维度会弱化）。
- 新能源/锂电属另一条产业链，不在「科技股」默认范围内，除非用户明确要求。
- 港股不在本部分范围，遇到先提示用户。

## 窗口与异动口径

| 项 | 默认 |
|---|---|
| 窗口 | 近 **5 个交易日**（`end = currentDate`，`start ≈ end − 9~10 自然日`） |
| 单日阈值 | ±**5**% |
| 短窗累计阈值 | ±**10**%，窗口 5 交易日 |

## 取数

```bash
python3 <skill目录>/scripts/fetch_ashare.py <code> --start <YYYYMMDD> --end <YYYYMMDD> \
    --day-threshold 5 --swing-threshold 10 --swing-window 5
```

- 三级通道：**akshare → 东方财富 → 新浪**。`akshare` 可选（`pip install akshare`，更全，含成交额/换手率），没装也能跑，后两者纯标准库。
- 被限频时自动下沉到新浪：**不复权**、无成交额/换手率，涨跌幅按相邻收盘价算，**报告须注明**。
- 输出 JSON：`meta`（代码/简称/板块/涨跌停幅度/窗口收益 `period_return_pct`）、`single_day_events`、`multi_day_swings`、`data_source`、`warnings`。
- 默认 `qfq`（前复权），除权除息机械跳空不会被误判为异动。

## 对比对象（共用骨架 §3）

- 先判断标的在 **芯片/半导体/AI 链** 的位置：上游（设备/材料/EDA/晶圆代工/存储）→ 中游（设计/制造/封测）→ 下游（终端/服务器/光模块/算力/云）。
- 选 **3~6 个关键上游 / 下游 / 同业 A股个股**，各跑一次同窗口脚本做联动对比表。
- 例：标的 +12%、上游设备股 +10%、下游算力股 +11% → 产业链共振；只有标的大涨、同业平淡 → 个股专属催化。

## 查因维度（共用骨架 §4）

- **个股消息面**：公告/业绩快报预告/订单/产能/扩产/中标/减持回购/股东/调研/诉讼。来源：东方财富 `data.eastmoney.com`、财联社 `cls.cn`、巨潮 cninfo 公告。
- **产业链上下游**：上游（光刻机/设备、硅片/材料、EDA、晶圆代工产能与报价、存储颗粒涨价）；下游（终端/手机/PC、AI 服务器、光模块/CPO、云厂资本开支 capex、算力需求）；同业（联动或抢单）。
- **海外映射**：美股对标（NVDA、TSMC、ASML、MU、AVGO 等）隔夜涨跌与财报、**费城半导体指数 SOX**、出口管制/实体清单——A股科技股常跟随隔夜美股半导体。
- **政策 / 资金 / 板块**：国产替代、大基金、出口管制、科创50/半导体ETF/AI 指数当日表现、北向资金、板块涨跌停潮、龙虎榜（游资 vs 机构席位）。
- **归因分层**：① 个股 alpha ② 产业链传导(上下游) ③ 板块/题材情绪 ④ 大盘系统性。

## 报告模板差异

- 元信息行：`> 数据源：<akshare/eastmoney/sina> ｜ 复权：<qfq/不复权> ｜ 板块：<...>（产业链位置：<上/中/下游>）`
- §2 表头：`| 个股 | 角色 | 同窗涨跌幅 | 一句话 |`，行依次为 标的 / 上游 / 下游 / 同业 / 半导体或AI板块（或 SOX）。
- §5 小节名：**产业链与海外映射**——上游（设备/材料/EDA/晶圆/存储价格与事件）、下游（终端/服务器/光模块/算力/云 capex）、海外（NVDA/TSMC/ASML/美光 + SOX 隔夜、出口管制）、政策/资金（国产替代/大基金、北向、板块涨跌停）。
- 会诊表流派行：技术·结构面(缠论) / 周期·宏观 / 卡脖子(Serenity) / 价值投资 / 事件驱动 / 加密叙事(让位)。

## 该市场特有的注意事项

- **涨跌停**：脚本按代码段+名称推断涨跌停幅度（主板±10、创业板/科创板±20、北交所±30、ST±5），涨停/跌停标注据此判定。
- **复权说明**：落到 sina 通道时为不复权，报告须注明。
- **产业链维度不能省**：很多 A股科技股的异动是产业链传导或隔夜美股映射，而非自身公告。
