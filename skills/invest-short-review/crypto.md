# 币圈部分 · invest-short-review

标的被判为 **加密资产** 时读本文，配合 SKILL.md 的共用骨架执行。本文只写币圈专属的部分。

## 适用范围（加密资产）

覆盖**任意加密货币个币**：BTC、ETH、主流山寨、Meme、L1/L2、DeFi、AI、RWA、DePIN、GameFi 等。**自动识别该币的板块叙事与生态**（如 SOL=L1、ARB=以太坊 L2、UNI=DeFi、某 AI agent 币=AI 叙事），据此选对比对象。

- 稳定币（USDT/USDC 等）本身波动极小，复盘意义有限——遇到先提示。
- 极冷门/新上线币可能不在 Binance/OKX/Coinbase，脚本会失败，改用 CoinGecko/DEX 数据并在报告注明。

## 窗口与异动口径

| 项 | 默认 |
|---|---|
| 窗口 | 近 **7 天**（自然日，24/7 无交易日概念；`end = currentDate`，`start ≈ end − 7 天`） |
| 单日阈值 | ±**8**% |
| 短窗累计阈值 | ±**20**%，窗口 7 天 |

阈值比股票高，是因为加密波动本身大得多；**别拿股票的 5%/10% 套加密**，会把正常波动当异动。

## 取数

```bash
python3 <skill目录>/scripts/fetch_crypto.py <SYMBOL> --start <YYYYMMDD> --end <YYYYMMDD> \
    --day-threshold 8 --swing-threshold 20 --swing-window 7
```

- 三级通道：**Binance → OKX → Coinbase**（公开行情、纯标准库，**无需装包、无需 API key**）。Binance/OKX 以 USDT 计价、Coinbase 以 USD 计价；某通道地域受限/限频时自动回退。
- 输出 JSON：`meta`（符号/交易对/计价/窗口收益 `period_return_pct`/最新价）、`single_day_events`（含 `amplitude_pct` 振幅、`quote_volume_musd` 成交额百万美元）、`multi_day_swings`、`data_source`、`warnings`。
- **K 线按 UTC 日切**；`end` 为今天时最后一根可能是**当日进行中 K 线**（pct 为实时、未走完），报告须注明。
- 三大所都查不到的冷门币：用 `WebSearch`/`WebFetch` 走 CoinGecko / CoinMarketCap / DEX 行情，手动给出近窗涨跌与异动，并注明数据源。

## 对比对象（共用骨架 §3）

- **必拉 BTC、ETH**（大盘 beta 基准），再选 **3~5 个同板块叙事 / 同生态** 的币，各跑一次同窗口脚本做联动对比表。
  - 例：标的是某 Solana 生态 Meme → 对比 BTC、ETH、SOL 以及其它热门 SOL 生态/Meme 币。
- 据此判断：**跟 BTC 大盘动（beta）**、**同叙事齐动（板块）**，还是 **个币独立 alpha**（涨跌幅明显偏离 BTC/ETH 与同类）。

## 查因维度（共用骨架 §4）

- **项目/币本身**：**代币解锁 / 线性释放 cliff**（对山寨砸盘极关键——查解锁日历）、上币/下架（Binance/Coinbase/Upbit listing 拉盘、下架砸盘）、主网/升级/分叉/空投快照、黑客/漏洞/脱锚、合作/集成/被采用、基金会或团队/做市商转账抛压、治理提案、回购销毁。来源：项目官博/官方 X、交易所公告、区块浏览器。
- **板块叙事**：同叙事币是否齐涨齐跌、叙事轮动、龙头带动。
- **大盘（BTC/ETH）**：BTC/ETH 当窗走势（绝大多数山寨跟随）、BTC.D（比特币市占）、TOTAL/TOTAL2、风险偏好 risk-on/off。
- **链上 on-chain**：交易所净流入/流出、巨鲸地址异动、稳定币供应、活跃地址；DeFi 看 TVL（DefiLlama）。来源：Arkham/Nansen/Glassnode。
- **衍生品 derivatives**：资金费率 funding、未平仓合约 OI、**多空爆仓 liquidations（连环爆仓常驱动急涨急跌——务必查）**、合约多空比。来源：Coinglass。
- **宏观 / 监管**：美联储/利率/DXY、与纳指相关性、**现货 ETF 资金流（BTC/ETH ETF）**、SEC/各国监管与执法、稳定币立法。
- **情绪**：恐惧贪婪指数 Fear & Greed、CT/社媒热度。
- **归因分层**：① 个币 alpha ② 板块叙事 ③ BTC/ETH 大盘 beta ④ 链上/衍生品（爆仓） ⑤ 宏观/监管。**时间对齐注意 UTC vs 本地时区**。

## forSkills 镜头权重（共用骨架 §6）

| 镜头 | 强度 | 说明 |
|---|---|---|
| `04-加密叙事博弈派-Vida` | 强 | 叙事阶段/情绪/资金费率/爆仓；叙事兑现日按 sell-the-news 读 |
| `02-周期宏观派` | 强 | 钟摆端/风险偏好/出清是否完成 |
| `05-技术结构面-缠论` | 强 | 中枢/背驰/量价 |
| `01-价值投资派` / `03-卡脖子供应链派-Serenity` / `06-事件驱动-特殊情境` | 让位 | 对绝大多数币不适用；仅 RWA / 有现金流 / 算力-DePIN 基础设施币可借用少量视角 |

- **缺数降级（币圈尤其常见）**：未取到 funding/OI/爆仓 或 链上净流/巨鲸/稳定币数据时，周期派的"钟摆出清"、Vida 派的"捡尸时点"必须降权、只给方向、标注"需 DYOR 补衍生品/链上"。
- **平静期**：区分高位横盘（出货嫌疑、偏减）与恐惧横盘（磨底、观望待出清）。
- 极恐 + 连环爆仓血洗按"捡尸"读。

## 报告模板差异

- 元信息行：`> 数据源：<binance/okx/coinbase>（<计价 USDT/USD>） ｜ 市场：加密 24/7 ｜ 板块/生态：<叙事·所属链>`
- §1 速览表**加一列**：`振幅/成交额`。
- §2 表头：`| 标的 | 角色 | 同窗涨跌幅 | 一句话 |`，行依次为 标的 / BTC（大盘）/ ETH（大盘·生态）/ 同叙事或同生态币。
- §5 小节名：**链上 · 衍生品 · 宏观/监管**——链上（交易所流入流出/巨鲸/稳定币/TVL）｜衍生品（funding/OI/爆仓）｜宏观监管（美联储/DXY/ETF 流/SEC/与美股相关性）｜情绪（恐惧贪婪）。
- §8 方向可用**"等右侧确认 / 出清后捡尸"**这类加密语境的明确条件；操作要点须给止损/失效位。
- §10 风险提示追加：**加密资产 24/7、波动极大、杠杆爆仓风险极高**，仓位/止损务必自行把关。
- 会诊表流派行：加密叙事(Vida) / 周期·宏观 / 技术·结构面(缠论) / 价值·Serenity·事件驱动(让位)。

## 该市场特有的注意事项

- **加密特性**：24/7、无涨跌停、波动远大于股票；K 线按 UTC 日切，`end=今天` 时最后一根可能进行中。
- **大盘/链上/衍生品维度不能省**：多数山寨的异动来自 BTC/ETH 带动、同叙事轮动或连环爆仓，而非自身消息；务必查联动、funding/OI/爆仓与解锁日历。
- **数据口径**：Binance/OKX=USDT、Coinbase=USD，不同所价格略有差异；Coinbase 通道无成交额。
- **噪音大**：传闻多、易被资金操纵，找不到原因就写"未找到明确催化（疑跟随大盘/爆仓/情绪）"，宁缺毋造。
