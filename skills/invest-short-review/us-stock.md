# 美股部分 · invest-short-review

标的被判为 **美股** 时读本文，配合 SKILL.md 的共用骨架执行。本文只写美股专属的部分。

## 适用范围（美股 + 科技股）

只做 **美股** 的 **科技股**，重点是 **半导体 / AI / 大型科技** 及紧邻环节：半导体设备/材料/EDA/IP、晶圆代工、芯片设计、存储/HBM、服务器/算力/数据中心、云计算、软件/SaaS、光模块/网络、消费电子。**ADR（如 TSM、ASML）视为美股可分析**。

- 用户给的若是**非科技股**（如银行/能源/医药）：先**提示不在本 skill 专长范围**，问是否仍要继续（仍可跑，但产业链/海外映射维度会弱化）。

## 窗口与异动口径

| 项 | 默认 |
|---|---|
| 窗口 | 近 **5 个交易日**（`end = currentDate`，`start ≈ end − 9~10 自然日`），交易日按**美东时间** |
| 单日阈值 | ±**5**% |
| 短窗累计阈值 | ±**10**%，窗口 5 交易日 |

美股**无涨跌停**、财报多在**盘后/盘前**，所以单日异动要拆 **隔夜 gap vs 日内**。

## 取数

```bash
python3 <skill目录>/scripts/fetch_usstock.py <TICKER> --start <YYYYMMDD> --end <YYYYMMDD> \
    --day-threshold 5 --swing-threshold 10 --swing-window 5
```

- 两级通道：**Stooq（CSV）→ Yahoo Finance Chart（JSON）**，均为纯标准库，**无需装包、无需 API key**。Stooq 偶发反爬/JS 墙时自动落到 Yahoo（Yahoo 偶发 429，脚本会换 query1/query2 与 period/range 多次尝试）。
- 输出 JSON：`meta`（代码/名称/复权口径/窗口收益 `period_return_pct`）、`single_day_events`（含 `gap_pct` 隔夜跳空 / `intraday_pct` 日内）、`multi_day_swings`、`data_source`、`warnings`。
- 口径：Stooq = 拆股调整价（未做分红调整）；Yahoo 通道 = 未复权 close。**报告须注明**。

## 对比对象（共用骨架 §3）

- 先判断标的在 **半导体/AI 链** 的位置：上游（设备 ASML/AMAT/LAM/KLA、代工 TSMC/Samsung/Intel、存储/HBM Micron/SK Hynix、EDA Synopsys/Cadence、IP Arm）→ 中游（设计/IDM）→ 下游（云厂 capex 微软/谷歌/亚马逊/Meta、服务器 Dell/SMCI、终端 Apple、光模块/网络 Coherent/Arista）。
- 选 **3~6 个关键上游 / 下游 / 同业**，优先**美股或 ADR**（TSM、ASML、AMD、AVGO、MU、SMCI、ARM），各跑一次同窗口脚本；**非美上市**（三星、SK 海力士等）只走新闻不取价。
- 板块基准：**SOX**、ETF **SMH/SOXX/QQQ**。

## 查因维度（共用骨架 §4）

- **个股消息面**：财报（**多在盘后**——优先看 `gap_pct` 大的日子是否对应财报/盘后消息）、指引 guidance、产品发布、大客户/订单、分析师评级与目标价、回购、内部人/13F、8-K/SEC、诉讼/监管。来源：公司 IR、SEC EDGAR、CNBC/Bloomberg/Reuters、Seeking Alpha。
- **产业链上下游**：上游（ASML/AMAT 订单与财报、TSMC 月度营收与产能/报价、HBM/存储涨价、EDA）；下游（云厂 capex 指引、AI 服务器需求 SMCI/Dell、苹果/终端、光模块/网络）；同业（AMD/AVGO/QCOM 联动）。
- **海外 / 宏观映射**：SOX、SMH/SOXX/QQQ、隔夜亚洲链（TSMC、三星、SK 海力士）；**美联储/利率/FOMC/CPI/PCE/就业**（科技股久期长、对利率敏感）、美元、**对华 AI 芯片出口管制**、台海地缘。
- **资金 / 情绪**：期权（gamma/0DTE）、ETF 资金流、标普/纳指、VIX、财报季节奏。
- **归因分层**：① 个股 alpha ② 产业链传导(上下游) ③ 板块/题材情绪 ④ 大盘/宏观系统性。**注意盘后财报对应次日 gap**。

- 元信息行：`> 数据源：<stooq/yahoo>（<复权口径>） ｜ 市场：美股 ｜ 产业链位置：<上/中/下游>`
- §1 速览表**加一列**：`隔夜gap/日内`。
- §2 表头：`| 个股 | 角色 | 同窗涨跌幅 | 一句话 |`，行依次为 标的 / 上游(ASML·TSM…) / 下游(SMCI·云厂…) / 同业(AMD·AVGO…) / SOX·SMH。
- §3 每次异动要注明**是否盘后财报 / 隔夜 gap**。
- §5 小节名：**产业链与海外/宏观映射**——上游（设备/代工/HBM/EDA）｜下游（云厂 capex/服务器/终端/光模块）｜同业｜海外宏观（SOX/SMH、亚洲链、美联储/CPI/就业、出口管制、美元/VIX）。
- §8 操作要点须注明"临近财报/隔夜 gap 波动放大，仓位与时点相应处理"。
- 会诊表流派行：技术·结构面(缠论) / 周期·宏观 / 卡脖子(Serenity) / 事件驱动 / 价值投资 / 加密叙事(让位)。

## 该市场特有的注意事项

- **美股特性**：无涨跌停；财报/指引多在盘后或盘前；交易日按美东时间，注意夏令时。
- **宏观维度不能省**：很多异动来自同业/SOX 联动、亚洲供应链隔夜或美联储/CPI 等宏观，而非自身公告。
- **取数失败**：Stooq 反爬 / Yahoo 429 时脚本会自动回退重试，仍失败则提示用户稍后再试或换网络，不要编数。
