# 投资标的 · 短期复盘（invest-short-review）

面向 **A股科技股 / 美股科技股 / 加密资产** 的 **短期**异动复盘。本文是三个市场共用的骨架，**市场专属细则在各自的市场文件里**，执行时必须先判市场、再读对应文件。

整条链路：**判市场 → 拉行情 + 识别异动（脚本，确定性）→ 拉对比标的做联动对比 → 逐个异动联网查因（多维度）→ forSkills 多派会诊 → 明确投资建议 → 写报告**。

> 最核心的产出：**最近这几天的剧烈涨跌到底为什么**，并且必须分清驱动来自哪一层。平静期没有大波动，也要给一份简报。
>
> **本 skill 不止于"为什么"——必须在事实归因与多派会诊之后，落到一份明确、可执行的投资建议（方向＋力度＋操作要点＋改判条件＋置信度）。这是硬要求，不许以"仅供研究/非投资建议"回避表态。**

## 执行步骤（共用骨架）

### 1. 解析输入
- 按上文「市场判定」定市场，**读对应市场文件**。
- 名称 → 代码 / ticker / 符号（用 `WebSearch` 核对，别张冠李戴）。
- 判断是否在该市场文件的适用范围内（不是就按其「适用范围」提示/确认）。
- 时间区间 → `--start`/`--end`（按 `currentDate` 算；默认见市场文件）。
- 确认输出目录（默认见上）。

### 2. 跑脚本拿主标的异动
用市场文件里给的脚本与阈值参数跑一次，先看 `ok`，再看 `data_source` 与 `warnings`（口径差异要写进报告）。

### 3. 拉对比标的做联动对比
对比对象由市场文件规定（A股/美股=产业链上下游+同业+板块指数；加密=BTC/ETH+同叙事+生态）。对每个对比标的用**同一窗口**跑同一脚本，读各自 `meta.period_return_pct` 做**联动对比表**，据此判断这次异动是 **beta（全链/板块/大盘一起动）** 还是 **alpha（自己单独动）**。

### 4. 逐个异动 + 平静期 联网研究（核心，务必多维度 + 诚实）
对**每个** `single_day_events` 和 `multi_day_swings`（平静期则对"近况"）联网查因。**查因维度清单见市场文件**，以下是三个市场共同的硬要求：

- **归因分层**（必做）：把每次异动拆到市场文件规定的层级上，能量化超额就量化（标的 vs 对比基准）。
- **时间对齐**：异动日与消息日对齐，分清"消息驱动"还是"提前反应/传闻"。
- **诚实第一**：只写有来源支撑的原因；**找不到明确催化就写「未找到明确催化（疑资金/情绪/技术性）」，绝不编造公告、数字、订单、解锁或链上数据**；每条附来源链接 + 日期 + 置信度（高/中/低）。

### 5. 平静期（窗口内无显著异动）
仍要产出简报：近窗温和涨跌、对比标的近况与消息、该市场的映射维度（见市场文件）、临近催化，并明确说明"本窗无触发阈值的剧烈异动"。

### 6. 投资流派复盘镜头会诊（forSkills · 必做）

事实归因完成后，**必须**再读取投资流派镜头，把"发生了什么"翻译成"各派会怎么看、会怎么做、什么消息会改判"。

- 读取目录 `/Users/aaron/workspace/llmWikis/investWiki/others/forSkills/`（可先读 `00-README` 了解合用法）。**哪几个镜头强、哪几个让位，按市场文件的权重表**。
- 对每个适配镜头，用其【二·信号映射表】【三·判定矩阵】套本次复盘的【归因层】【临近催化】【拥挤度/估值】，给出该派"判读 + 动作建议(买/加/持/减/清/观望) + 理由"；本窗无该派抓手或非适配 → 标注"让位/沉默"（这是正确的）。
- **缺数降级（强制）**：本 skill 通常不产出估值分位、现金流、以及加密的 funding/OI/爆仓/链上净流——据此判定的流派要**降权、只给方向不给精确买卖点、并标注"需 DYOR 补数据"**。
- **平静期也做**：按各镜头的"平静期行"给判读（多为观望/维持原判），不空手。

### 7. 形成明确投资建议（硬要求 · 本 skill 的落点）

§6 给的是"各派怎么看"；本步**必须**收敛成一份明确、可执行的投资建议：

- **方向 + 力度**：买入 / 加仓 / 持有 / 减仓 / 清仓 / 观望，必须明确表态其一（不许只罗列"有人看多有人看空"就收尾）；并给建议仓位/力度（轻/标准/重）。加密可用"等右侧确认 / 出清后捡尸"这类该市场语境的明确条件。
- **操作要点**：入场/分批区间、止盈、止损/失效位——数据允许时给具体价位/区间；**缺关键数据时只给方向与思路并标注"需自行确认点位/DYOR"**（缺数降级照旧，但不得因此回避表态）。
- **分情形**：偏多情形(若…成立)→动作 ｜ 偏空情形→动作 ｜ 基准情形→动作。
- **时间视角**：区分"短期(本窗～数周)"与"需更长视角"的建议。
- **改判条件**：承接 §6 的 listen-for，写清触发哪些新消息则升级/降级本建议。
- **置信度**：给本建议整体置信度(高/中/低)＋主要风险；执行与最终拍板由用户负责，但本步必须先给出清晰立场。

### 8. 写报告

## 注意事项（共用）

- **先判市场再动手**：没读市场文件就跑脚本 / 套阈值，是最容易出错的地方（加密用股票阈值会漏掉一半异动）。
- **短期高频用**：窗口、阈值都可调；如需**长期复盘**，显式给更长区间并放大阈值/窗口。
- **对比维度不能省**：哪怕标的自己没消息，也要看产业链/同业/大盘是否在动——很多异动是传导或跟随，而非自身事件。
- **诚实归因**：事后归因有局限，找不到原因就如实写"未找到明确催化"，标注置信度，宁缺毋造。
- **必须给出明确投资建议**（方向＋力度＋操作要点＋改判条件＋置信度），并附风险与降权说明；不得以"仅供研究/非投资建议"回避表态。
