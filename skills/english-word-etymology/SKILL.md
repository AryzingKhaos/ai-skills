# English Word Etymology · 词源 + 文化 单词卡

输入**一个英语单词或短语/习语**，联网查证后产出一张「词源 + 文化」卡片。理念：**学语言就是学文化**——单词最好的记忆钩子往往就是它的词源故事与文化典故，所以把词源讲成故事、把同根词连成网络、把名句/歌/影视作为第二层锚点，让「背单词」和「文化」合一。

整条链路：**输入归一 → 联网查证多源 → 合成卡片(两套模板) → 终端打印 + 存 Markdown 归档 + 更新索引**。

---

## 触发约束（硬约束）

**只在用户显式调用时触发**：`/english-word-etymology <词>`、"用/调用 english-word-etymology 查 X"、"查一下 X 这个词的词源/联想/文化出处"。用户只是在句子里提到某个英文词、不算调用。

## 0. 输入归一

1. **判类型**：单词 vs 短语/习语（含 ≥2 词、或 Achilles' heel / break the ice 这类固定表达）→ 决定用哪套模板。
2. **单词还原原形**：running→run、better→good、mice→mouse、went→go；卡片里**标出原始输入与还原结果**（如 "running → run"）。变形本身有讲究的（如 -ing 来历）可一句带过。
3. 多义词：以**最核心/最常用**的义项为主线，其它主要义项简述；词源通常一个源头，语义分化在「历史语义演变」里讲。

## 1. 联网查证（必须联网；每条出处可核验）

按下表抓取、交叉验证。**铁律**：第六类「文化出处」每一条都必须**实际打开来源确认该词确实出现**、并在卡片里附**来源链接**；查不到可靠来源的就**不写**，绝不编造歌词/台词/名言或张冠李戴。

| 内容 | 权威来源 |
|---|---|
| 音标 / 词性 / 释义 | `https://api.dictionaryapi.dev/api/v2/entries/en/<word>`（JSON：音标+释义+例句）、Wiktionary |
| 词源 / 历史演变 | **etymonline** `https://www.etymonline.com/word/<word>`、**Wiktionary** `https://en.wiktionary.org/wiki/<word>` |
| 词根词缀 + 🌟同根词家族 | Wiktionary 的 Related/Derived terms、etymonline 的 root 交叉链接、对词根（如 spec-/greg-/astro-）反查同根词 |
| 名人名言 | **Wikiquote** `https://en.wikiquote.org`、Wikipedia |
| 诗句 / 文学 | **opensourceshakespeare.org**（莎翁全文索引，可定位具体剧目/行）、Project Gutenberg、poetryfoundation、Wikipedia |
| 歌曲歌词 | Genius `genius.com` 检索；确认词确实在歌词/标题里 |
| 电影 / 电视剧台词 | Wikiquote、IMDb quotes、Wikipedia |
| 习语 / 谚语 / 典故 | Wiktionary、`idioms.thefreedictionary.com`、phrases.org.uk |
| 兜底 | 通用 Web 搜索 "`<word>` etymology / famous quote / in song / in movie / origin"，再回到上面权威源核实 |

> 实操：先 WebFetch etymonline + dictionaryapi + Wiktionary 拿到硬核词源与释义；再针对「文化出处」做有的放矢的搜索+核实。**够用即可、不灌水**，但词源/同根词要扎实。

## 3. 输出

- **默认两者都出**：① 终端完整打印这张卡片；② 存 Markdown 文档（不需要额外命令，默认就存）。
- **保存路径**：`/Users/aaron/workspace/英语学习/EnglishWordWiki/<word>.md`（文件名用还原后的原形、全小写；习语用空格转连字符，如 `break-the-ice.md`）。目录不存在则先建。
- **更新索引**：维护 `/Users/aaron/workspace/英语学习/EnglishWordWiki/index.md`，每个词一行：`- [<word>](<word>.md) — <一句话词源亮点>`。按字母序插入、已存在则更新该行（不要重复追加、不要覆盖整文件）。
- 若该词的 `.md` 已存在：可直接打开复用/更新，不必从零重查（除非用户要求刷新）。

## 坑位备忘
- **绝不编造**文化出处：歌词、台词、名言、"出自某诗第几行" 一律要先打开来源确认；模型记忆不可信，必须落到链接。宁可少写。
- **同根词反查**：很多词的记忆价值在词根家族，别只给孤词；拿到词根后主动反查一串亲戚词。
- etymonline 偶尔对生僻词无收录 → 退到 Wiktionary 的 Etymology 段。
- dictionaryapi.dev 对短语/生僻词可能 404 → 用 Wiktionary 拿音标释义。
